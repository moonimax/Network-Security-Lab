R1# - 장비의 현재 상태를 보고, 일회성 동작을 실행하는 곳이다.
- show ip interface brief(인터페이스 상태 보기)
- show running-config(현재 설정 보기)
- ping, reload(재부팅), copuy(설정 저장)

R1(config)# -  장비의 설정 자체를 바꾸는 곳
- hostname R1(이름 바꾸기)
- interface g0/0 (특정 인터페이스 설정하러 들어가기)
- ip route ... (경로 추가)
